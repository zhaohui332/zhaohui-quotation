# 江苏兆辉防腐科技 · 报价单工作台

这是一个保存在本机文件夹里的报价单工具。双击「启动报价单.command」后，在浏览器打开 `http://127.0.0.1:4731` 即可使用。

## 使用方法

1. 在「编辑报价」里填写收件单位、项目名称、报价单号和有效期。
2. 在「产品报价明细」里逐行填写序号、名称、材质、规格、数量、单位、单价、总价和备注；数量乘单价会自动计算，总价也可以手工修改。
3. 在「商务条款与说明」里写付款方式、交货周期、质保期限以及报价备注。
4. 在「资质与认证」里录入证书名称、证书编号等，导出的报价单会展示在表格中。
5. 进入「图片素材」上传产品照片、车间设备、资质证书或公司 Logo，勾选后在右侧预览中选用。上传的图片保存在本目录的「素材」文件夹，可反复使用。
6. 在「公司资料」中填写企业概况、基本情况、主要设备、资质照片和业绩；这些内容填写一次后会自动固定接在每份报价单后面。
7. 上传「厂门 / 厂区」照片并在公司资料中选择，它会成为报价单第一页封面，封面会自动写“客户单位报价及技术说明、江苏兆辉防腐科技有限公司、日期”。
8. 点右上角「Word」或「PDF」直接导出文件，或先点「保存」留作历史记录。

## 数据保存位置

- 当前草稿：`data/current.json`
- 报价历史：`data/quotes.json`
- 公司资料：`data/company.json`
- 素材文件：`素材/厂门厂区`、`素材/产品照片`、`素材/车间设备`、`素材/资质证书`、`素材/公司Logo`
- 所有数据都只保存在这台电脑的这个文件夹里，不上传网络。

## 注意

- 报价单号默认按「公司资料」里的前缀自动生成，可手动修改。
- 导出的 PDF 直接生成到下载目录；Word 文件也是标准 `.docx`，可直接用 WPS 或 Microsoft Word 继续修改。
- 证书编号、收款账号、公司地址等信息请按真实资料填写。
